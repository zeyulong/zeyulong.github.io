发明专利skill的使用

本文最后更新于 2026年9月9日 上午

本文主要分享了发明专利skill handsomestWei/patent-disclosure-skill 的使用。

概述

发明专利skill

  • https://github.com/handsomestWei/patent-disclosure-skill：中国专利.skill，从项目文档到可交付的技术交底书，专利点挖掘、联网国知局查新、脱敏成文与自检闭环。通俗解读专利，嗅探政策动向，辅助审查答复。

其它资源：

  • https://github.com/7toCR/paper2patent：面向科研成果转化的论文转专利智能模板库，提供 Flash/Pro Prompt、专利附图生成与 Agent Skills，辅助规范生成中国发明专利申请文本。
    • 单一Prompt不便于全局、长时间规范agent？
    • handsomestWei/patent-disclosure-skill的规范更分步和细致，还配套了多个脚本。

项目结构

  • 本技能遵循 AgentSkills 常见布局：仓库根目录即技能根目录，内含 SKILL.md。

  • 入口 SKILL.md：触发词、工具对照表、主流程顺序、迭代规则；

  • 目录 prompts/：每一步的详细指令（录入、扫描、专利点分析、查新、预览、成文、自检、迭代合并/纠正等）；

  • 目录 tools/：.docx/.pptx 转 Markdown、mermaid → PNG、Markdown → Word、修订对话记录等脚本；

  • 工具说明：tools/README.md。

目录约定：

技能入口与agent流程

  • 详见入口文件：patent-disclosure-skill/SKILL.md
  • 主入口：prompts/disclosure/
  • 交底书模版细则
  1. 项目扫描：它按优先级读文档和代码。遇到 docx 或 pptx 也不慌，先调用 docx_to_md.py 或 pptx_to_md.py 转成 Markdown 再扫，避免 Agent自动跳过Office。大仓库它会先用搜索定位，不会傻乎乎从头到尾读一遍。
  2. 专利点挖掘：扫完项目，它不会直接甩一份交底书给你。它会先跟你讨论候选专利点，融合、筛选，定下来再往下走。这一步在 prompts/patent_points_analyzer.md 里管着，Agent 每步执行前都会 Read 对应文件。
  3. 国知局查新与差异化：查新优先联网检索中国专利公布公告站 epub.cnipa.gov.cn，用 cnipa_epub_search.py 爬取。它要求分多次调用，每次只传一个词块，然后自己按 pub_number 合并结果。国知局爬不动或没结果，再降级到 WebSearch，查到的著录和外链直接写入交底书第一章（prior_art_search.md）。
  4. 交底书成稿：成稿用脱敏模板，3.2 系统框图和 3.4 流程图都用 fenced mermaid 写，出Markdown版本。定稿时执行 mermaid_render.py 把 mermaid 转成 PNG，默认再出一份同名的 docx（细节见 tools/README.md），代理人拿到直接就能改。
  5. 交付命名：凡落盘交付的文件，命名规则是 {案件名}_{YYYYMMDDHHmmss}.md 和同名 docx。带时间戳，不会覆盖旧版本，便于版本追溯。
  6. 自检闭环：定稿后它内部跑一遍自检，检查逻辑闭环、公式与参数一致性。自检不写入正文，在后台完成。这一步由 prompts/disclosure_self_check.md 管着。
  7. 迭代追溯：初版交底书出来后，你要补充材料或纠错，不用特意说"迭代"。Agent 识别到意图后直接 Read iteration_context.md，再选 merger.md（合并新材料）或 correction_handler.md（纠错）（走不同的prompt）。结果另存为新文件，同时把对话记录追加到 交底书修订对话记录.md。

依赖

默认交底需要什么（发明主路径）：

  1. 创建环境：

  2. 安装依赖：

  3. 本机 Google Chrome 或 Microsoft Edge（推荐，多数电脑已有）。出图与查新共用，不必再装 Node / npm / mmdc。

    1. 探测是否已能启动浏览器：

      • ok=true：可直接定稿出图、跑国知局检索。
      • 没有 Playwright 包：再执行一次上面的 pip install -r requirements.txt。
      • 本机既无 Chrome 也无 Edge：才执行 python -m playwright install chromium（整机一次即可）。

    2. 无可用浏览器时，发明仍可先交 Markdown（mermaid 围栏保留）；Word 里框图可能先是代码块，补齐浏览器后重跑 tools/shared/mermaid_render.py 即可。

  4. （可选，推荐）国知局查新：若需使用交底轻量查新 skills/patent-disclosure/tools/crawl/cnipa_epub_search.py（一词一页）或著录检索 skills/patent-search/tools/cnipa_search.py（epub.cnipa.gov.cn）：

    未装或探测失败时，Step 5 仍可按该 prompt 降级为 WebSearch（Google 学术无专利类型过滤；Google Patents 支持 PATENT/DESIGN，实用新型靠关键词+国知局）。

  5. （可选）申请文件（须显式；须指定交底目录）：把已有交底产出改写成权利要求书、说明书、摘要与黑白附图。不另装依赖（PyYAML + 已有 python-docx / playwright）。不做 TIFF。

    缺材料时门禁退出码为 2，应先回到交底技能补齐。细则见 skills/patent-application/SKILL.md。

  6. （可选）案卷会稿（须显式）：把交底书和申请文件串成一趟：按发明人/工程师给的材料成文，申请问题清单上的缺口最多改三轮。

  7. （可选）审查答复案例库：显式触发「审查答复 / 案例入库 / /oa」后使用。配置与向量库默认在操作系统文档目录：{Documents}/patent-disclosure-skill/oa/（PATENT_OA_HOME 可覆盖）。推荐智谱 embedding-3；亦支持 DashScope / MiniMax / 本地 / OpenAI（config.py set --preset …）。

    细则见 skills/patent-oa/prompts/、skills/patent-oa/tools/README.md、skills/patent-oa/SKILL.md。

  8. 安装LibreOffice以方便大模型调用文档渲染检查功能。

  9. 可选：STEP 多视角解析（默认关闭）

  10. 外观 / 实用新型线稿（成文前必做）

  11. 专利通俗解读 + Obsidian 库

  12. 完成。

图示定稿：需 Node.js；在 tools/ 下 npm install 或使用 npx 调用 mermaid-cli（mmdc），详见 tools/README.md。

运行

怎么开口：

我已经在电脑本地使用Anaconda创建了patent-disclosure-skillConda环境，并安装了一些Python Package。因此，当你需要运行Python脚本时，你可以直接在PowerShell 7终端中使用conda activate patent-disclosure-skill进入该Conda环境。如果你需要在该Conda环境下安装其它Python Package或执行其它与Conda环境相关的操作，需要先告诉我并得到我的允许才能进行。

示例案件：集成式电驱桥壳体（实用新型 · 文生图）

  • 交底书：专利挖掘、交底书、查新、实用新型、外观设计等；/patent-disclosure-skill、/交底书。
  • 通俗解读：读专利、公开号 / PDF 且目标为理解；/patent-read、/读专利。
  • 交底书迭代：已有交底上补材料/纠错 → disclosure/iteration_context.md → merger / correction_handler；另存时间戳稿。
  • 技能进化旁路：技能进化、政策/审查动向嗅探、政策雷达、审查政策更新、自进化、/patent-evolve、/技能进化。
  • 审查答复 / 案例入库 / 经验手册：审查意见、意见陈述、OA、补正通知书、案例入库、书籍蒸馏、实务书、/oa、/审查答复。
类型 典型场景 触发示例
发明 方法 / 系统 / 算法流程 「按发明写交底」「项目路径 …」
实用新型 形状、构造、连接与装配 「实用新型」「一种…装置/结构」
外观设计 外形、图案、色彩或其结合 「外观设计」「设计说明 / 视图」

已有交底上补材料或纠错时，按 merger.md / correction_handler.md 另存新稿（实用/外观改图或主题时同步 figure_plan）。细则见 SKILL.md、prompts/disclosure/intake.md。

查新这一步，Agent 会优先跑国知局公布公告站，如果已有交底书文件要修改，Agent 识别到意图后自动进入迭代模式，不用你特意说"迭代"两个字。

专利类型：支持 发明、实用新型、外观设计 三种专利类型，未显式指定时交底默认发明；材料更偏实用/外观时在汇总或预览阶段反问（见 disclosure/intake.md）。

交底书模版细则

示例

子技能列表

技能 名称 能力 触发 详情
patent-disclosure 交底书编写 不会写专利也没关系：材料丢进来，挖出真正能保护的点、查一圈在先技术，直接变成能交差的交底书（发明 / 实用新型 / 外观分套模板） 「交底书」 详情
patent-application 申请文件 交底别再停在「给所里看的草稿」——一口气改成权要、说明书、摘要和黑白附图，说不清的进问题清单，不卡死整套文件 「申请文件」· 「申请底稿」 详情
patent-docket 案卷会稿 角色扮演交底工程师 vs 专利代理师：自主多轮规划工作流，材料一丢就出交底和申请，清单最多对打三轮，缺事实就问、绝不瞎编 「交底申请一起做」· 「从零出交底和申请」 详情
patent-reader 通俗解读 专利全文读不下去：公开号或 PDF 丢进来，换成普通人能看懂的笔记和图谱；推进 Obsidian 后能串起多件专利关联、画出专利地图 「读专利」 详情
patent-oa 审查答复辅助 审查意见别对着发懵：拆条款问答、起草答复稿；个人从业经验和实务书专家技巧蒸馏进库，RAG 检索增强辅助答复 「审查答复」· 「审查意见」 详情
patent-search 著录检索 人名、公司、分类号照查；更能扔一张产品图或一段权要，倒推出检索式去翻公布公告 「著录检索」 详情
patent-exam-policy 政策简报 对照国知局官网近期政策消息出人话简报，分析技能里哪些交底技巧、申请书式可能过时，审查口径一变就能跟上 「政策简报」· 「政策雷达」 详情

静态IP和链式代理

v2rayN

前提，需要一个能连通的其它节点。

  1. v2rayN-顶部工具栏-订阅分组-订阅分组设置。

  2. 订阅分组设置窗口-点击左上角“添加”：

    1. 别名
    2. 前置代理配置别名-选择配置
    3. 其它配置项
    4. 确定

  3. 关闭订阅分组设置窗口。

  4. 在v2rayN窗口上方选中新建的订阅分组。

  5. v2rayN-顶部工具栏-配置项-添加[SOCKS]。

    听说SOCKS要比HTTP要好，比如在本地挂代理运行大模型的时候，网络环境更保真，不易泄露。

    1. 别名
    2. 地址
    3. 端口
    4. 用户名
    5. 密码
    6. 其它配置项
    7. 确定

  6. 可以测试是否连通了：右键新建的节点-测试真连接延迟。

    HTTP 商业代理有时不一定能正确响应 v2rayN 的测速逻辑，所以测速失败不一定代表不能用。

    很多住宅代理服务商除了账号密码认证外，还有一层 IP 白名单认证。即使账号密码对了，如果发起请求的本地公网 IP 不在服务商的白名单里，服务器也会拒绝连接并断开。

  7. 完成。

路由配置

域名匹配规范

域名写法：

  • domain:完整域名 -> 例如 domain:google.com (匹配该域名及其子域名)
  • keyword:域名关键字 -> 例如 keyword:google (包含该关键字的都匹配)
  • regexp:正则表达式 -> 高级用法，用于复杂匹配
  • full:完全匹配字符串 -> 必须完全一致，极少使用
  • geosite:域名集 -> 引用预定义列表，例如 geosite:cn (中国境内域名)

域名的格式有以下几种形式：

  • https://www.v2fly.org/config/dns.html#dnsobject
  • https://xtls.github.io/config/routing.html#ruleobject
  • 纯字符串：当此域名完整匹配目标域名时，该规则生效。例如 v2ray.com 匹配 v2ray.com 但不匹配 www.v2ray.com。
  • 正则表达式：由 regexp: 开始，余下部分是一个正则表达式。当此正则表达式匹配目标域名时，该规则生效。例如 regexp:\.goo.*\.com$ 匹配 www.google.com、fonts.googleapis.com，但不匹配 google.com。
  • 子域名 (推荐)：由 domain: 开始，余下部分是一个域名。当此域名是目标域名或其子域名时，该规则生效。例如 domain:v2ray.com 匹配 www.v2ray.com、v2ray.com，但不匹配 xv2ray.com。
  • 子串：由 keyword: 开始，余下部分是一个字符串。当此字符串匹配目标域名中任意部分，该规则生效。比如 keyword:sina.com 可以匹配 sina.com、sina.com.cn、www.sina.com 和 www.sina.company，但不匹配 sina.cn。
  • 预定义域名列表：由 geosite: 开头，余下部分是一个名称，如 geosite:google 或者 geosite:cn。名称及域名列表参考 预定义域名列表。

IP写法：

  • geoip:IP集 -> 例如 geoip:cn (中国 IP)
  • 单个IP -> 例如 8.8.8.8
  • IP段 -> CIDR 格式，例如 192.168.1.0/24

如果是特定进程需要代理，可以在规则中的 process (进程) 栏填写进程名称（如 chrome.exe）。

全局模式下绕过指定的几个网站

  1. 顶部工具栏-设置-路由设置-预定义规则集列表-双击打开“V4-全局(Global)”

  2. 规则集设置窗口-顶部工具栏-添加规则：

    1. 别名：绕过自定义网站

    2. outboundTag：direct

      • proxy: 走代理的 domain 和 IP
      • direct: 直连的，不经过代理
      • block: 阻塞的（直接断网），一般用于屏蔽广告或恶意 IP

    3. 在左下方的Domain栏中填入，示例：域名匹配规范

      每行结尾用英文逗号,隔开。

    4. 确定。

  3. 保存规则后，在规则列表界面，务必将这条新规则上移置顶。

    路由匹配是从上到下进行的。特定规则必须在通用规则（如“绕过大陆”或“全局代理”）的上面，否则会被通用规则覆盖（拦截）。

  4. 完成

全直连

通过配置路由规则来实现当使用系统代理“自动配置系统代理”或“Tun模式”时，实际网络还是直连的？即没有走代理。

  1. v2rayN-设置-路由设置-一键导入规则集
  2. 删除新增的“绕过大陆”和“全局”规则集，保留新增的“黑名单”规则集。
  3. 双击进入新增的“黑名单”规则集。
    1. 修改别名为“V4-全直连(Direct)”
    2. 排序：4
    3. 双击规则列表里的“代理Google”，取消开启别名“代理Google”右侧的按钮，确定。
    4. 如此依次取消开启“代理海外公共DNSIP”、“代理海外公共DNS域名”、“代理IP”和“代理GFW”。
    5. “规则集设置”窗口，确定。
  4. “路由设置”窗口，确定。
  5. 完成。
